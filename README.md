# Golf-Web

A single-page landing website for Sidcup Family Golf, featuring a full-screen background video, a custom cursor, and smooth scroll-driven animations powered by GSAP and ScrollTrigger. Built with plain HTML, CSS, and JavaScript.

## Features

- Full-screen autoplay hero video
- Custom cursor with a trailing blur effect
- Animated navigation bar and scroll-triggered section transitions
- Marquee-style scrolling text ticker
- Interactive cards with hover overlays
- Testimonial, gallery, and footer sections
- GSAP ScrollTrigger-based scroll animations

## Tech Stack

- HTML
- CSS
- JavaScript (vanilla)
- GSAP and ScrollTrigger (via CDN)
- Remix Icon (via CDN)

## Getting Started

Open `index.html` in a browser:

```bash
# from the project directory
start index.html
```

The GSAP and Remix Icon libraries are loaded from CDNs, so an internet connection is required for animations to work.
